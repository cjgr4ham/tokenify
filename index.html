        Learn the mathsShort, plain-language explanations
        What does “1 in 137,500” mean?

        Every chest has the same tiny probability, 1/137,500 (about 0.000727%), of containing a Pirate Token. It describes one chest; it does not mean a token is scheduled to appear every 137,500 chests.

        Why doesn’t opening 137,500 chests guarantee a token?

        Each chest is independent. Across 137,500 chests the chance of at least one token is 1 − (137,499/137,500)137,500 ≈ 63.2%. About 36.8% of players who open exactly that many would still have none.

        Expected value is an average, not a promise

        The expected number of tokens is n/137,500. It is the long-run average over many players or many repeats, and it is usually not a whole number. Any single run can land above or below it.

        How the chance grows with more chests

        The chance of at least one token after n chests is 1 − (1 − p)n. It rises quickly at first and then flattens out, approaching but never reaching 100%.

        Long losing streaks don’t make a token “due”

        Chests have no memory. After 100,000 empty chests the next one is still exactly 1 in 137,500, and the expected wait for the next token is still 137,500 chests. Believing otherwise is the gambler’s fallacy.

        How the binomial distribution works

        If you open n independent chests, each with probability p, the number of tokens X follows Binomial(n, p): P(X = k) = C(n, k) · pk · (1 − p)n−k. The chart above plots exactly this.

        What a prediction interval means

        A central 95% range is a span of token counts that about 95% of independent runs would land inside. Because counts are whole numbers, the actual coverage is usually a little higher than the target. It is not a confidence interval: the drop rate is already known.

        Why simulated results bounce around the average

        Randomness creates spread. The typical distance from the expected count (the standard deviation) is √(np(1 − p)), so bigger runs land closer to the average in relative terms, but not in absolute terms.

        Exact odds versus rounded percentages

        TOKENIFY never computes with rounded figures like “0.00073%”. It uses the exact fraction 1/137,500 and numerically stable methods, and tells you when a value is below what can be displayed at the chosen precision.

        Why two simulations of the same size differ

        Each simulation is a fresh set of independent random draws. Two runs of a million chests can easily differ by several tokens; that variation is exactly what the distribution chart predicts.
